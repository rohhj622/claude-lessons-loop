# claude-lessons-loop

세션이 끝나면 그 세션의 맥락은 사라진다. 지난주에 틀린 방식으로 이번 주에 다시 틀린다.

이 플러그인은 **이번 세션에서 겪은 실수 하나를 받아, 다음 세션의 Claude 가 비슷한
상황에서 자동으로 받는 경고 문장으로 되돌린다.** 주입된 결과는 이렇게 생겼다.

```
이 프롬프트와 의미가 가까운 교훈 (검색: qmd 의미검색, 관련도 0~1,
중요도=INDEX의 impact. 참고용 — 무관하면 무시할 것):

- [관련도 0.52 · 중요도 high] [[LSN-2026-08-05-001]] 안 불리는 규범은 조용히 낡는다
```

무슨 말을 하든 이 세 줄이 발화 앞에 붙어 모델에게 간다.

---

## 설치

```
/plugin marketplace add rohhj622/claude-lessons-loop
/plugin install claude-lessons-loop@claude-lessons-loop
```

플러그인을 켜면 Claude Code 가 **기록 폴더 경로를 묻는다.** 그 하나만 정하면 된다.
나머지는 설정 스킬이 물어 가며 채운다.

```
/claude-lessons-loop:configure
```

이 스킬은 상태를 먼저 보여 주고, 빠진 것마다 승인을 받아 채운다. 이미 있는 파일은
덮지 않는다. 언제 다시 돌려도 되고, 교훈이 안 붙을 때 무엇이 빠졌는지 보는 용도로도
쓴다. 상태만 보려면 이것만 돌려도 된다.

```bash
sh "$CLAUDE_PLUGIN_ROOT/hooks/py.sh" doctor.py
```

**기록 폴더를 안 정하면 훅들은 아무것도 하지 않는다.** 세션 시작에 한 줄로 그
사실만 알린다. 설치만 하고 설정을 안 한 사람의 작업을 막지 않기 위해서다.

> ⚠ **이미 같은 훅을 `settings.json` 에 손으로 걸어 둔 사람은 설치하면 안 된다.**
> 더해지는 방식이라 둘 다 돈다 — 교훈이 두 번 주입되고 재색인도 두 번 돈다.
> 옮겨 탈 거면 `settings.json` 의 해당 훅을 먼저 지운다.

### 사람이 해야 하는 것은 둘뿐이다

**1. 의미검색을 쓰고 싶으면 qmd 를 직접 깐다.** 안 깔아도 된다.

```bash
npm i -g @tobilu/qmd
qmd update && qmd embed
```

첫 색인에서 모델 셋(합계 2 GB 안팎)을 내려받는다. 전부 GGUF 로 이 PC 에서 돌고,
그 뒤로는 검색에 API 호출이 없다. 전역 설치와 2 GB 다운로드는 이 기계의 상태를
바꾸는 일이라 **플러그인이 대신 하지 않는다.**

> **검색이 로컬이라는 뜻이지, Claude 사용 전체가 로컬이라는 뜻은 아니다.**
> 모델 호출 자체는 밖으로 나간다. 이 구분을 흐리지 말 것.

**2. `templates/CLAUDE.md` 에서 쓸 절을 고른다.** 어느 조항이 자기한테 맞는지는
편집 판단이라 자동화하지 않는다. `configure` 가 절 목록을 보여 주고 고른 것만
승인받아 옮긴다.

## 검색기 둘

| | 기본 검색기 | qmd |
|---|---|---|
| 설치 | 없음 | 전역 npm + 모델 2 GB |
| 방식 | 글자 겹침 | 의미검색 + 재순위 |
| 왕복 (맥 실측) | 0.02초 | 웜 1.3~4.6초 · 콜드 55.6초 |

qmd 가 잡히면 qmd 를 쓰고, 없거나 실패하면 기본 검색기가 받는다. **어느 쪽으로
뽑았는지가 주입 문구에 적힌다.** 눈금이 달라서 같은 0.4 가 다른 뜻이기 때문이다.
좋은 매치가 qmd 는 0.5~1.0, 기본 검색기는 0.3 안팎이라 임계값도 따로 둔다.

qmd 가 타임아웃되거나 실패하면 **왜 그랬는지도 같이 낸다.** 유사도 미달이라 안
붙은 것과 도구가 죽어서 안 붙은 것은 화면에서 똑같이 생긴다.

## 설정

`/plugin` 에서 이 플러그인의 설정을 열면 다섯 개가 있다.

| 값 | 기본 | 뜻 |
|---|---|---|
| 기록 폴더 | (필수) | 이 아래에 `Lessons/` 가 생긴다 |
| 상시 주입 묶음 이름 | `검증·판단 방법론` | `INDEX.md` 의 이 묶음에서 high 만 매 세션 들어간다 |
| 회수 유사도 하한 | `0.35` | qmd 눈금 |
| 기본 검색기 유사도 하한 | `0.12` | 겹침 눈금. 위와 값을 맞추면 안 된다 |
| 한 발화에 붙일 교훈 수 | `3` | 많이 넣으면 컨텍스트를 먹는다 |
| 검색 제한 시간 | `12`초 | 훅 제한(15초)보다 작아야 한다. 크게 잡으면 잘린다 |

값은 `~/.claude/settings.json` 에 저장되고 **플러그인을 갱신해도 남는다.**
환경변수(`LESSONS_VAULT` · `QMD_BIN` · `QMD_INDEX`)를 주면 그쪽이 이긴다.

> **훅 파일을 직접 고치지 말 것.** `${CLAUDE_PLUGIN_ROOT}` 아래는 플러그인이
> 소유하는 자리라 `/plugin update` 가 덮어쓴다. 고쳐 놓은 값이 조용히 사라진다.

## ⚠ 먼저 읽을 것

**`Lessons/INDEX.md` 의 칸 이름을 바꾸지 않는다.** 훅이 이 표를 기계로 읽는다.
칸 이름은 `ID · 제목 · 중요도 · 날짜` 넷이다. **순서는 바꿔도 된다** — 이름으로
찾는다. 이름을 바꾸거나 지우면 교훈이 안 붙고, 그때는 빈칸이 아니라 왜 못 읽었는지가
나온다.

**교훈을 쓴 뒤 qmd 색인을 갱신해야 한다.** 안 하면 방금 쓴 교훈은 의미검색에 안
잡힌다. 갱신을 닷새 빼먹어 교훈 25건(당시 29%)이 조용히 빠져 있었던 적이 있고, 그
사이 이미 있는 교훈과 반대되는 교훈을 새로 쓰는 일이 벌어졌다. 그래서 이 플러그인은
갱신을 세 겹으로 방어한다. 기본 검색기는 색인이 없어서 이 문제가 없다.

## 무엇이 들어 있나

### 훅 넷 (`hooks/`)

| 시점 | 파일 | 하는 일 |
|---|---|---|
| SessionStart | `session-start.py` | `INDEX.md` 의 지정 묶음에서 중요도 high 인 행만 넣는다. **검색을 안 쓴다** — 색인이 낡아도 이쪽은 산다 |
| SessionStart | `tagscan.py` | 노트 끝에 흘러든 닫는 태그 오염을 훑는다. 탐지만 하고 고치지 않는다 |
| UserPromptSubmit | `lesson-recall.py` | 발화를 그대로 검색어로 써서 가까운 교훈을 붙인다 |
| SessionEnd | `session-end.py` | 교훈이 색인보다 새것일 때만 `qmd update && embed` 를 돌린다 |

`startup` 과 `clear` 에서 돈다. `/clear` 뒤에도 상시 교훈이 살아 있게 하기 위해서다.

**모든 훅은 어떤 경우에도 `exit 0` 으로 끝난다.** 훅이 작업을 막아서는 안 된다.

거드는 파일 넷이 더 있다. `paths.py`(경로와 설정값 해석), `index_md.py`(표를 읽는
유일한 자리), `search.py`(검색기 둘), `doctor.py`(점검기).

### 스킬 둘 (`skills/`)

- `/claude-lessons-loop:configure` — 설정과 점검. 승인 없이 아무것도 고치지 않는다.
- `/claude-lessons-loop:wrap` — 세션 마무리. 계획한 일과 실제 한 일을 갈라 적게 하고,
  **교훈 후보는 사람 승인 뒤에만 파일로 만든다.** 승인 단계를 뺐더니 겪지도 않은
  일이 교훈으로 적히는 일이 있었다.

### 서브에이전트 (`agents/`)

`lessons-writer` — 스키마 지켜 쓰는 사서. 정형·반복 쓰기용이고 모델은 sonnet 이다.

### 템플릿 (`templates/`)

기록 폴더 뼈대, 스키마 문서, 검사기 둘(`lint.py` · `drift.py`), CLAUDE.md 뼈대.
`configure` 가 복사한다. **이미 파일이 있으면 덮지 않는다.**

## 낡지 않게 하는 장치

기록은 쓰는 순간부터 낡는다.

| 장치 | 어디 | 무엇을 막나 |
|---|---|---|
| 조건부 재색인 | `session-end.py` | 갱신을 사람이 빼먹는 것 |
| 대역 내 경고 | `lesson-recall.py` | 조용한 실패. **검색이 죽어도 경고는 나간다** |
| 폴백 사유 표시 | `search.py` | 유사도 미달인지 도구가 죽었는지 구분 안 되는 것 |
| WAL 함정 대응 | 위 둘 | SQLite 는 새로 쓴 내용을 `-wal` 에 먼저 넣어 본체 mtime 이 멈춘다. 방금 갱신한 색인이 낡아 보여 경고가 상시 점등하면 사람이 그 경고를 무시하게 된다. 둘 중 **더 최신인 쪽**을 색인 시각으로 본다 |
| 스키마 검사 | `_Meta/lint.py` | `impact` 누락, 어휘 이탈, `INDEX.md` 행 누락 |
| 드리프트 검사 | `_Meta/drift.py` | 끊긴 링크, 없는 파일 경로, 손으로 적어 둔 총계, 중복 ID |
| 양성 대조 | `tagscan.py` · `lint.py` · `drift.py` · `session-start.py` | 넷 다 **대상 0건을 성공이 아니라 도구 실패로 보고한다.** 깨끗해서 0인지 못 찾아서 0인지 구분이 안 되면 그 0은 근거가 아니다 |

주기적 재색인까지 원하면 `qmd update && qmd embed` 를 예약 작업으로 걸어 둔다.
예약 작업은 로그인 셸의 `PATH` 를 물려받지 않으므로 `node` 와 qmd 진입점을
**절대경로로** 적어야 한다.

## 실측

> **아래 숫자는 이 플러그인 코드로 잰 값이 아니다.** 같은 방식을 `settings.json` 에
> 손으로 걸어 쓰던 전신 환경(Windows, 한 달, 표본 1명)에서 나온 값이다.
> 이 저장소의 코드로 다시 재면 그때 바꾼다. 잘 된 것만 적으면 취지에 어긋나므로
> 출처를 밝히고 남겨 둔다.

- 교훈 노트 **160건**. 그중 같은 원인이 반복된 다섯 가지를 상시 규칙으로 승격했다.
- 훅 대상 발화 **395건 중 191건(48.4%)** 에 교훈이 붙었다.
- **그런데 정작 필요한 순간에 맞는 교훈이 온 것은 8번 중 2번이다.**
  같은 실수를 다시 해서 기존 노트에 `## 재현` 을 붙인 사건이 8번 있었고,
  그날 관련 교훈이 실제로 떠 있었던 것은 그중 2번뿐이다.
- 안 붙은 204건 중 182건이 **유사도 미달인지 타임아웃인지 구분되지 않았다.**
  설계 실수였고, 지금은 `search.py` 가 그 사유를 남긴다.

**붙는 것과 맞는 것은 다르다. 뒤쪽은 아직 못 풀었다.** 원인 후보는 셋이다 —
임계값이 높은가, 상위 3건 제한에 밀리는가, 아니면 질문은 증상으로 오는데 교훈
제목은 원인으로 적혀 있어서인가. 아직 대조해 보지 않았다.

## 환경

파이썬 3 이 있어야 한다. 없으면 훅들이 조용히 통과한다. Node 는 qmd 를 쓸 때만
필요하고, `_Meta/drift.py` 만 PyYAML 이 필요하다.

**어느 조합에서 실제로 돌려 봤는지는 [docs/platforms.md](docs/platforms.md) 에
있다.** 안 재본 칸은 비워 두지 않고 "안 재봤다"고 적어 두었다. 빈칸은 통과로
읽히기 때문이다.
