# claude-lessons-loop

세션이 끝나면 그 세션의 맥락은 사라진다. 지난주에 틀린 방식으로 이번 주에 다시 틀린다.

이 플러그인은 **이번 세션에서 겪은 실수 하나를 받아, 다음 세션의 Claude 가 비슷한
상황에서 자동으로 받는 경고 문장으로 되돌린다.** 주입된 결과는 이렇게 생겼다.

```
이 프롬프트와 의미가 가까운 교훈 (참고용, 무관하면 무시할 것):

- [관련도 0.52 · 중요도 high] [[LSN-2026-08-05-001]] 안 불리는 규범은 조용히 낡는다
```

무슨 말을 하든 이 세 줄이 발화 앞에 붙어 모델에게 간다.

---

## ⚠ 먼저 읽을 것 두 가지

1. **`Lessons/INDEX.md` 표의 칸 순서를 바꾸지 않는다.** 훅 두 개가 이 표를 기계로
   읽는다. 칸이 밀리면 **에러가 나지 않고** 교훈이 제목 없이 나오거나 아예 안 붙는다.
   칸은 `ID · 제목 · 중요도 · 날짜` 넷이다.
2. **교훈을 쓴 뒤에는 검색 색인을 갱신해야 한다.** 안 하면 방금 쓴 교훈은 검색에
   안 잡힌다. 색인 갱신을 닷새 빼먹어 교훈 25건(당시 29%)이 조용히 빠져 있었던 적이
   있고, 그 사이 이미 있는 교훈과 반대되는 교훈을 새로 쓰는 일이 벌어졌다.
   그래서 이 플러그인은 갱신을 **세 겹**으로 방어한다(아래 참조).

---

## 설치

```
/plugin marketplace add rohhj622/claude-lessons-loop
/plugin install claude-lessons-loop@claude-lessons-loop
```

플러그인 훅은 기존 `settings.json` 을 **덮어쓰지 않고 더해진다.** 설정 파일을
직접 고칠 필요가 없다.

> ⚠ **이미 같은 훅을 `settings.json` 에 손으로 걸어 둔 사람은 설치하면 안 된다.**
> 더해지는 방식이라 둘 다 돈다 — 교훈이 두 번 주입되고 SessionEnd 재색인도 두 번
> 돈다. 파일 이름이 같아도 별개 사본이라 서로를 못 알아챈다.
> 옮겨 탈 거면 `settings.json` 의 해당 훅을 먼저 지운다.
> 그냥 한 번 보고 싶은 거라면 설치하지 말고 `claude --plugin-dir <이 폴더>` 로 띄운다.

### 그다음, 손으로 해야 하는 것 넷

플러그인 설치가 대신 해 주지 않는 부분이다. 넷 다 해야 실제로 돈다.

**1. 기록 폴더를 만들고 환경변수로 가리킨다**

```bash
mkdir -p ~/notes/Lessons ~/notes/_Meta
cp -r templates/vault/. ~/notes/
export LESSONS_VAULT="$HOME/notes"        # 셸 프로필에 넣는다
```

Windows PowerShell 이면:

```powershell
[Environment]::SetEnvironmentVariable('LESSONS_VAULT', "$HOME\notes", 'User')
```

`LESSONS_VAULT` 가 없으면 훅들은 **아무것도 하지 않고 조용히 통과한다.**
설치만 하고 설정을 안 한 사람의 세션을 막지 않기 위해서다.

**2. 검색 도구를 설치한다**

```bash
npm i -g @tobilu/qmd
```

`templates/qmd/index.yml` 을 `~/.config/qmd/index.yml` 로 복사하고 두 경로를
자기 폴더로 고친다. `lessons` 컬렉션 이름은 바꾸지 않는다 — 훅이 그 이름을 부른다.

```bash
qmd update && qmd embed
```

첫 실행에서 모델 3종(임베딩 · 질의확장 · 재순위, 합계 2.6 GB 안팎)을 내려받는다.
전부 GGUF 로 이 PC 에서 돌고, 그 뒤로는 검색에 API 호출이 없다.

> **검색이 로컬이라는 뜻이지, Claude 사용 전체가 로컬이라는 뜻은 아니다.**
> 모델 호출 자체는 밖으로 나간다. 이 구분을 흐리지 말 것.

**3. 상수 셋을 자기 기록에 맞춘다** — `hooks/lesson-recall.py` 맨 위에 모여 있다.

| 상수 | 기본값 | 뜻 |
|---|---|---|
| `MIN_SCORE` | `0.35` | 이 유사도 아래는 버린다 |
| `MAX_HITS` | `3` | 한 발화에 붙일 교훈 수 |
| `QMD_TIMEOUT` | `12` (초) | 이 안에 검색이 안 끝나면 그 발화는 교훈 없이 넘어간다 |

> `QMD_TIMEOUT` 은 `hooks/hooks.json` 의 훅 `timeout`(15초)보다 **반드시 작아야 한다.**
> 크게 잡으면 훅이 먼저 죽어서, 색인이 낡았다는 경고까지 같이 사라진다.
> 20초로 잡았다가 실제로 그렇게 만든 적이 있다.

**4. `templates/CLAUDE.md` 에서 쓸 절을 자기 `~/.claude/CLAUDE.md` 로 옮긴다.**

---

## 확인

```bash
python hooks/paths.py       # VAULT / QMD / INDEX 가 전부 OK 로 나와야 한다
sh hooks/session-start.sh   # 상시 교훈 목록이 나와야 한다
```

`hooks/paths.py` 가 `MISSING` 을 내면 그 줄의 설정부터 고친다.
**빈 출력을 "정상"으로 읽지 말 것** — 이 저장소의 첫 번째 교훈이 정확히 그것이다.

## 무엇이 들어 있나

### 훅 넷 (`hooks/`)

| 시점 | 파일 | 하는 일 |
|---|---|---|
| SessionStart | `session-start.sh` | `Lessons/INDEX.md` 의 지정 묶음에서 `중요도 = high` 인 행만 awk 로 뽑아 넣는다. **검색을 안 쓴다** — 색인이 낡아도 이쪽은 산다 |
| SessionStart | `tagscan.py` | 노트 끝에 흘러든 닫는 태그 오염을 훑는다. 탐지만 하고 고치지 않는다 |
| UserPromptSubmit | `lesson-recall.py` | 발화를 그대로 검색어로 써서 의미가 가까운 교훈 3건을 붙인다. 색인이 낡았으면 경고를 같이 낸다 |
| SessionEnd | `session-end.py` | 교훈이 색인보다 새것일 때만 `qmd update && embed` 를 돌린다 |

**모든 훅은 어떤 경우에도 `exit 0` 으로 끝난다.** 훅이 작업을 막아서는 안 된다.

### 스킬 (`skills/wrap/`)

`/claude-lessons-loop:wrap` — 세션 마무리. 계획한 일과 실제 한 일을 갈라 적게 하고,
**교훈 후보는 사람 승인 뒤에만 파일로 만든다.** 승인 단계를 뺐더니 겪지도 않은 일이
교훈으로 적히는 일이 있었다.

### 서브에이전트 (`agents/`)

`lessons-writer` — 스키마 지켜 쓰는 사서. 정형·반복 쓰기용이고 모델은 sonnet 이다.
노트 하나 고치는 정도면 메인 세션이 직접 써도 된다.

### 템플릿 (`templates/`)

기록 폴더 뼈대, 스키마 문서, 검사기 둘(`lint.py`·`drift.py`), qmd 설정, CLAUDE.md 뼈대.
**자동으로 설치되지 않는다.** 위 1번에서 직접 복사한다.

## 낡지 않게 하는 장치

기록은 쓰는 순간부터 낡는다. 여섯 겹으로 막는다.

| 장치 | 어디 | 무엇을 막나 |
|---|---|---|
| 조건부 재색인 | `session-end.py` | 갱신을 사람이 빼먹는 것 |
| 대역 내 경고 | `lesson-recall.py` 의 `stale_index_note()` | 조용한 실패. **검색이 타임아웃으로 죽어도 경고는 나간다** |
| WAL 함정 대응 | 위 둘 | SQLite 는 새로 쓴 내용을 `-wal` 에 먼저 넣어 본체 mtime 이 멈춘다. 방금 갱신한 색인이 낡아 보여 경고가 상시 점등하면 사람이 그 경고를 무시하게 된다. 둘 중 **더 최신인 쪽**을 색인 시각으로 본다 |
| 스키마 검사 | `_Meta/lint.py` | 필드 누락·어휘 이탈·본문 12줄 초과 |
| 드리프트 검사 | `_Meta/drift.py` | 끊긴 링크, 없는 파일 경로, 손으로 적어 둔 총계, 중복 ID |
| 양성 대조 | `tagscan.py`·`lint.py`·`drift.py` | 셋 다 **대상 0건을 성공이 아니라 도구 실패로 보고한다.** 깨끗해서 0인지 못 찾아서 0인지 구분이 안 되면 그 0은 근거가 아니다 |

주기적 재색인까지 원하면 `qmd update && qmd embed` 를 30분마다 도는 예약 작업으로
걸어 둔다. 예약 작업은 로그인 셸의 `PATH` 를 물려받지 않으므로 `node` 와 qmd 진입점을
**절대경로로** 적어야 한다.

## 실측 (표본 1명, 한 달)

정직하게 적는다. 잘 된 것만 적으면 이 저장소의 취지에 어긋난다.

- 교훈 노트 **160건**. 그중 같은 원인이 반복된 다섯 가지를 상시 규칙으로 승격했다.
- 훅 대상 발화 **395건 중 191건(48.4%)** 에 교훈이 붙었다. 붙은 것의 94% 는 3건을 다 채웠다.
- **그런데 정작 필요한 순간에 맞는 교훈이 온 것은 8번 중 2번이다.**
  같은 실수를 다시 해서 기존 노트에 `## 재현` 을 붙인 사건이 8번 있었고,
  그날 관련 교훈이 실제로 떠 있었던 것은 그중 2번뿐이다.
- 안 붙은 204건 중 182건이 **유사도 미달인지 타임아웃인지 구분되지 않는다.**
  훅이 그 구분을 기록하지 않는다. 설계 실수다.

**붙는 것과 맞는 것은 다르다. 뒤쪽은 아직 못 풀었다.** 원인 후보는 셋이다 —
`MIN_SCORE` 가 높은가, 상위 3건 제한에 밀리는가, 아니면 질문은 증상으로 오는데
교훈 제목은 원인으로 적혀 있어서인가. 아직 대조해 보지 않았다.

## 환경

Windows 11 · Claude Code 2.1.238 · Node 20+ · Python 3.8+ 에서 만들었다.
WSL 과 Git Bash 양쪽에서 도는 것까지는 확인했다. **macOS·Linux 에서는 재보지 않았다.**
`hooks/paths.py` 가 `~` 기준으로 경로를 잡으므로 돌 것으로 보지만, 실측한 값이 아니다.

`drift.py` 는 PyYAML 이 필요하다 (`pip install pyyaml`).
