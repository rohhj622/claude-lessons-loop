# 교훈 목록 (INDEX)

> ⚠ **이 표는 훅 두 개가 기계로 읽는다.** 칸 순서는 `ID · 제목 · 중요도 · 날짜` 로
> 고정이다. 칸을 밀거나 열을 추가하면 **에러 없이** 교훈이 제목 없이 나오거나
> 아예 안 붙는다. 손으로 고쳤으면 다음 세션에서 주입이 정상인지 눈으로 확인한다.
>
> - `hooks/session-start.sh` — 아래 `GROUP` 절에서 `중요도 = high` 인 행만 뽑는다
> - `hooks/lesson-recall.py` — 검색이 찾은 ID 로 이 표에서 제목과 중요도를 가져온다
>
> 세션 시작 훅의 대상 묶음 이름은 `session-start.sh` 의 `GROUP` 변수에 있다.
> 기본값은 아래 첫 절과 같은 `검증·판단 방법론` 이다. 절 이름을 바꾸면 훅도 바꾼다.
