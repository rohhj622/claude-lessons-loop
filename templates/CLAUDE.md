# CLAUDE.md — 상시 규칙 (뼈대)

> `~/.claude/CLAUDE.md` 에 놓거나, 이미 있으면 필요한 절만 옮겨 붙인다.
> **이 파일은 매 세션 통째로 컨텍스트에 들어간다. 길이가 곧 비용이다.**
> 200줄 안팎을 상한으로 두고, 넘으면 스킬이나 별도 문서로 뺀다.

---

## 여기 적을 것과 적지 말 것

**적을 것** — 실행할 것이 없고, 문장 자체가 있는 것만으로 효과가 나는 규칙.

**적지 말 것** — 실행을 요구하는 지시. "매 세션 X 파일을 열어 읽어라" 같은 것.
세션 165건을 세어 보니 그런 지시가 실제로 실행된 비율은 10% 였다. 같은 일을
훅으로 옮겼더니 세션 시작 훅은 100%, 발화마다 도는 훅은 85% 였다.

> **안 지켜지는 조항을 남겨 두지 않는다.** 지켜지는 조항까지 같이 의심받는다.
> 준수율을 재 보고, 안 지켜지면 훅으로 옮기거나 지운다.

## 검증 습관

> 교훈(LSN)이 쌓여 같은 원인이 3건을 넘으면 여기에 한 줄로 올린다.
> 올려도 원본 LSN 은 지우지 않는다 — 조건과 재현 경로가 다르다.
> 아래 다섯은 예시이자, 실제로 그렇게 승격된 것들이다.

- **"없음"을 결론짓기 전에 양성 대조를 한다.** 도구가 실패해 빈 출력인지,
  정말 없어서 빈 결과인지 구분할 것.
- **문서·설정 파일·코드 추론은 라이브의 정본이 아니다.** 저장소의 export·README·
  시점 스냅샷 문서로 현재 상태를 주장하지 말 것. 돌아가는 것에서 실측한다.
- **A/B 대조나 독립 검토 전에는 원인을 단정하지 않는다.**
  "확정" "원인은 X다" 를 대조군 없이 쓰지 말 것.
- **조용한 실패를 먼저 의심한다.** 성공 종료코드·빈 결과·"빨라졌다"는 증거가
  아니다. 무엇이 처리됐는지 건수로 확인한다.
- **Windows 네이티브 명령(`schtasks`·`reg`·`netsh`)은 PowerShell 로 부른다.**
  Git Bash 는 `/query` 같은 슬래시 플래그를 경로로 변환한다.

## 기록

- 기록 폴더는 `LESSONS_VAULT` 가 가리키는 곳이다. 스키마는 `_Meta/스키마.md`.
- 교훈은 훅이 알아서 넣어 준다. **세션 시작마다 `Lessons/INDEX.md` 를 열지 않는다.**
  INDEX 를 직접 여는 것은 교훈 체계 자체를 손볼 때뿐이다.
- 세션 서사의 정본은 커밋 메시지다. 별도 일지 노트를 만들지 않는다.
- **자격증명·키 값은 기록에 남기지 않는다. 환경변수 이름까지만 남긴다.**

## 하지 않을 것

> 여기 적는 것은 **지킬 수 있는 것만**이다. 못 지킬 절대 금지는 가장 먼저 썩는다.
> 진짜로 막아야 하는 것은 문장이 아니라 `PreToolUse` 훅으로 막는다 —
> 도구가 도는 직전에 코드가 판정하면 성실성에 기대지 않아도 된다.

- 운영 DB 쓰기(INSERT/UPDATE/DELETE/DDL) 직접 실행 금지. SQL 만 만들어 넘긴다.
- 살아 있는 서버·클러스터를 바꾸는 명령은 먼저 물어본다.
  읽기만 하는 명령은 그냥 해도 된다.
